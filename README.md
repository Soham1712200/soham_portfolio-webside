# Personal Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript. It is ready to publish with GitHub Pages.

## Customize

The portfolio is filled with the details found in the supplied résumé. Review the project descriptions and links in `index.html` to ensure they match your work. The résumé page is `assets/resume.html`; it has a **Print / Save as PDF** button. The original editable Pages document is available at `assets/Editable_Full_Stack_Web_Developer_Resume_Template.pages`.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.

The site will be published at `https://<username>.github.io/<repository>/`.
